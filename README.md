# Fake News Detection System

## About the Project
This project uses Machine Learning and Natural Language
Processing (NLP) to identify fake and real news articles.

## Technologies Used
- Python
- Machine Learning
- TF-IDF
- Logistic Regression
- Streamlit
- Scikit-learn

## Features
- News text input
- Text preprocessing
- Fake and real news prediction
- Simple user interface

## Model
TF-IDF Vectorizer and Logistic Regression.
